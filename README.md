# Telegram Task Manager Bot (Python)

Продуманный минималистичный менеджер задач для Telegram:
- быстрое создание задачи;
- выбор даты (с кнопками и ручным вводом);
- выбор времени (с кнопками и ручным вводом);
- хранение задач в SQLite;
- напоминания в точное время;
- управление задачами (`/list`, `/done`, `/delete`);
- поддержка таймзоны пользователя.

## Архитектура

- `bot.py` — логика Telegram-бота, диалоги, валидация, фоновые напоминания.
- `storage.py` — слой хранения (SQLite), CRUD и выборка задач к напоминанию.
- `tasks.db` — создаётся автоматически при первом запуске.

## Команды

- `/start` или `/help` — справка
- `/new` — создать задачу
- `/list` — показать активные задачи
- `/done <id>` — отметить задачу выполненной
- `/delete <id>` — удалить задачу
- `/timezone <Zone>` — установить таймзону, например `Europe/Moscow`
- `/cancel` — отменить создание задачи

## Установка

1. Установи Python 3.11+.
2. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен.
3. Установи зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

4. Создай `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
DEFAULT_TIMEZONE=Europe/Moscow
DB_PATH=tasks.db
```

5. Запусти:

```bash
python bot.py
```

## UX-детали, почему это удобно

- **Быстрый поток создания задачи**: сначала текст, потом день, потом время.
- **Готовые кнопки времени**: 09:00, 12:00, 15:00, 18:00, 21:00.
- **Fallback на ручной ввод**: можно ввести любую дату/время вручную.
- **Защита от ошибок**: бот не даст сохранить задачу в прошлом.
- **Локальная таймзона**: пользователь может выбрать удобную зону через `/timezone`.
- **Лаконичные уведомления**: напоминание приходит ровно в момент дедлайна.

## Идеи для улучшения

- Добавить категории (`Работа`, `Личное`, `Учёба`) и приоритет.
- Повторяющиеся задачи (ежедневно/еженедельно).
- Напоминания «за 10 минут» + «в момент дедлайна».
- Экспорт в Google Calendar / iCal.
- Inline-кнопки в уведомлении: «✅ Done», «🔁 Перенести на 1ч».
