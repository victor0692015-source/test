# 🚀 CRM System Documentation

## 📋 Overview

Документ описывает целевой функционал CRM-системы уровня amoCRM для управления продажами, лидами и коммуникациями с современным дизайном в стиле Apple iOS.

> Статус: **Product Vision / Roadmap**. Текущая кодовая база уже реализует базовый CRM-контур (авторизация, компании, карточка компании, заметки, задачи, активность), а этот документ фиксирует расширяемую модель продукта.

---

## ✨ Основные возможности

### 🏢 Управление компаниями
- ✅ Добавление компаний с логотипами и цветами
- ✅ Поиск и фильтрация
- ✅ Удаление компаний (защита паролем: **12345**)
- ✅ Настройка отображения (размер иконок, колонки, метки)

### 📊 Dashboard
- 📈 Ключевые метрики (лиды, сделки, выручка, конверсия)
- 📋 Обзор задач (сегодня, открытые, выполненные)
- 🎯 Визуализация воронки продаж
- 📅 Недавние лиды

### 👥 Leads (Лиды)
- ➕ Добавление лидов с полной информацией
- ✏️ Редактирование и удаление
- 📞 Быстрые действия (звонок, email)
- 🏷️ Статусы: New, Contacted, Qualified, Lost
- 📍 Источники: Website, Referral, Social Media, Cold Call, Event
- 👤 Назначение менеджера
- 📝 Детальная карточка лида

### 💼 Pipeline (Воронка продаж)
- 🎯 Drag & Drop Kanban board
- 📊 6 этапов сделки:
  - New Lead
  - Contacted
  - Negotiation
  - Proposal
  - Won ✅
  - Lost ❌
- 💰 Отслеживание стоимости сделок
- 📈 Статистика по воронке
- ➕ Добавление новых сделок

### ⏱️ Timeline (История)
- 📝 Добавление событий
- 📞 Типы: Call, Email, WhatsApp, Telegram, Meeting, Document
- 📅 Группировка по датам
- 🎨 Цветные иконки по типам

### 📁 Projects (Проекты)
- ➕ Добавление проектов
- ✏️ Редактирование (название, статус, прогресс, дедлайн)
- 🗑️ Удаление проектов
- 📊 Прогресс-бар
- 🏷️ Статусы: Active, Paused, Completed

### ✅ Tasks (Задачи)
- ➕ Создание задач с приоритетом
- 🔄 Переключение статусов: Open → In Progress → Completed
- 🎯 Приоритеты: Low, Medium, High
- 📅 Установка дедлайнов
- 🗑️ Удаление задач
- 📊 Разделение на открытые/завершенные

### 👤 Contacts (Контакты)
- ➕ Добавление контактов
- ✏️ Редактирование и удаление
- 📧 Email и телефон
- 💼 Роль/должность
- 🎨 Аватары с инициалами

### 💰 Finance (Финансы)
- 🧾 Управление инвойсами
- 💵 Статусы: Paid, Pending, Overdue
- 📊 Автоматический подсчет:
  - Total Revenue
  - Pending Amount
  - Overdue Amount
- ➕ Добавление/редактирование/удаление инвойсов

## 🎯 Использование

### Добавление компании
1. Нажмите кнопку "Add" на главном экране
2. Заполните форму:
   - Название (обязательно)
   - URL логотипа (опционально)
   - Цвет иконки
   - Revenue
   - Количество проектов
   - Количество задач

### Работа с лидами
1. Откройте компанию
2. Перейдите на таб "Leads"
3. Нажмите "Add Lead"
4. Заполните информацию
5. Используйте кнопки Call/Email для быстрых действий

### Управление воронкой
1. Откройте таб "Pipeline"
2. Перетаскивайте сделки между этапами (Drag & Drop)
3. Добавляйте новые сделки кнопкой "Add Deal"
4. Отслеживайте статистику внизу страницы

### Настройка отображения
1. Нажмите иконку ⚙️ в поисковой строке
2. Выберите размер иконок
3. Настройте количество колонок
4. Включите/выключите метки

### Удаление компании
1. Откройте компанию
2. Нажмите меню (⋮) в правом верхнем углу
3. Выберите "Delete Company"
4. Введите пароль: **12345**
5. Подтвердите удаление

## 🎓 Best Practices

### Добавление новых компаний
- Используйте логотипы из Unsplash или загрузите свои
- Выбирайте контрастные цвета для лучшей видимости
- Заполняйте все поля для полной статистики

### Работа с лидами
- Указывайте источник для аналитики
- Назначайте менеджера сразу
- Обновляйте статус при каждом контакте

### Управление задачами
- Устанавливайте реалистичные дедлайны
- Используйте приоритеты корректно
- Переводите в "Completed" только выполненные
